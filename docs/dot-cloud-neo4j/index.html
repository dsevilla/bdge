    Cómo se construye el grafo

    Las transparencias llevan la etiqueta :Tr, y las que abren sección también :Seccion. Como en Neo4j, no hay esquema que declarar: el grafo sale de estas sentencias. Las escrituras duran hasta restablecer los datos o recargar la página.
