Laboratorio de modelado Cassandra

Practica claves de partición, columnas de clustering y consultas dirigidas por el modelo con un pequeño simulador de CQL que funciona en el navegador.

Qué se está simulando

Este laboratorio implementa un subconjunto educativo de CQL. Puedes crear tablas, cargar ocho filas sintéticas, observar las particiones y consultar sus filas. El boletín de Cassandra se ejecuta contra Cassandra real; esta página sirve para razonar sobre el esquema antes de conectarte a un clúster.

No es un clúster Cassandra: no simula nodos, tokens, replicación, consistencia, latencia, índices, TTL, contadores ni colecciones. Si una construcción válida de Cassandra queda fuera del subconjunto, la aplicación lo indica como «No implementado en este simulador».

Subconjunto disponible
  • CREATE TABLE, DROP TABLE, tipos int, bigint, text, boolean y timestamp.
  • Claves simples y compuestas, clustering y CLUSTERING ORDER BY.
  • INSERT con upsert, y SELECT con igualdad, intervalos, LIMIT y ALLOW FILTERING.
  • No se aceptan IN, OR, agregaciones, UPDATE, DELETE ni ORDER BY de la consulta.
