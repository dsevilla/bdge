Stack Overflow en español

Preparando SQLite…

Al abrir la página se intenta cargar Stack Overflow desde dos fragmentos XZ del repositorio dsevilla/bd2-data. Si falla, puedes usar la muestra, abrir una copia local o probar el fichero comprimido de la release. La base se carga una vez y se comparte entre todas las páginas de ejercicios.

Descargar .db.gz

Las consultas se muestran en bloques de 100 filas; ejecuta una sentencia cada vez. Puedes retroceder en consultas SELECT. La descarga alternativa usa el fichero .db.gz de la release; si no se puede cargar desde la web, descárgalo y ábrelo con «Abrir un fichero local».

Compatibilidad: la página ejecuta SQLite en el navegador, no MySQL 8. Los ejercicios de la sesión 2 adaptan la sintaxis; el particionado, MATCH ... AGAINST y EXPLAIN ANALYZE de MySQL no se pueden ejecutar aquí.

La base no se envía a ningún servidor. Esta práctica usa SQLite en el navegador; no emula MySQL 8. Los ejercicios cubren consultas portables y adaptan algunas funciones. El particionado, MATCH ... AGAINST, el tipo JSON de MySQL y EXPLAIN ANALYZE no funcionan aquí con la sintaxis de clase.
